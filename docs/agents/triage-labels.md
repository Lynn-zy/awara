# Triage Labels

各工程技能围绕 5 个标准分类角色（canonical triage roles）协作。本文件将这些标准角色映射为本仓库 Issue Tracker 中实际使用的标签字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning                                    |
| -------------------------- | -------------------- | ------------------------------------------ |
| `needs-triage`             | `needs-triage`       | 需要维护者评估此 Issue                     |
| `needs-info`               | `needs-info`         | 等待提交者补充更多信息                     |
| `ready-for-agent`          | `ready-for-agent`    | 需求规格已完整明确，可交由后台 Agent 实现  |
| `ready-for-human`          | `ready-for-human`    | 需要人工介入开发实现                       |
| `wontfix`                  | `wontfix`            | 不予处理                                   |

当技能提及某个分类角色（例如“添加 AFK-ready 分类标签”）时，请使用上表 `Label in our tracker` 列对应的标签名。

如需调整实际标签命名，可直接修改上表中的 `Label in our tracker` 列。
